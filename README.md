# Workout 365

Workout 365 is a mobile-friendly adaptive workout tracker. The scheduled plan responds to the user's profile, including fitness level, primary goal, days per week, workout duration, preferred cardio, and available equipment.

## Included files

- `index.html` - main application
- `manifest.webmanifest` - installable web-app settings
- `sw.js` - offline caching/service worker
- `icon-192.png` - app icon
- `icon-512.png` - app icon
- `README.md` - repository information

## Publish with GitHub Pages

1. Upload all six files to the root of the repository.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save, then open the GitHub Pages URL when deployment completes.

## Data

User profiles and workout history are stored locally in the browser. Do not clear site data unless you have exported/backed up workout history.
